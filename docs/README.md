# Documentation

This project follows the Divio documentation system, with four types of documentation:

| Section | Purpose |
| --- | --- |
| [Tutorials](tutorials/README.md) | Learning-oriented lessons that guide a newcomer through a complete example. |
| [How-to guides](how-to-guides/README.md) | Task-oriented instructions for achieving a specific goal. |
| [Reference](reference/README.md) | Precise descriptions of interfaces, parameters, and other technical facts. |
| [Explanation](explanation/README.md) | Background, reasoning, assumptions, and methodological discussion. |

Start with [your first replication](tutorials/first-replication.md), use [the command guide](how-to-guides/reproduce-results.md) for specific tasks, and consult [the current replication audit](reference/replication-audit.md) before interpreting or sharing results. The [initial reconciliation report](reference/table-reconciliation.md) is historical; the [provenance follow-up](reference/table2-provenance-recovery.md) describes the revenue model now integrated into the default workflow.
