# Exact regression checks

Run from the repository root, or use an absolute path from another directory:

```sh
Rscript --vanilla tests/check_regression.R
```

The test explicitly runs the original ACS specification with `run_replication(table2_specification = "acs")` and optional Table 2 diagnostics in a temporary workspace, using the same dependencies as the main workflow. It checks:

- 18 exported CSVs, including tables, model membership, analytic panels, and comparisons, against frozen checksums.
- Both full prepared panels against frozen RDS objects, including values, types, ordering, and attributes.
- All seven models' coefficients, covariance matrices, residuals, fitted values, model frames, and residual degrees of freedom.
- Both sets of sensitivity bounds.
- Source modules define functions without running the analysis.

The fixtures were captured on 2026-11-08 **before the readability refactor**, after the staging reorganization had been verified. They represent the recovered analysis, not a claim that all numbers match the paper. The original Table 2 and Table 3 discrepancies are intentionally preserved in these historical fixtures. The default workflow now promotes the independently recovered revenue-based Table 2 fit; that intentional change is tested separately rather than overwriting the original expectations. The [published targets](../data/reference/published_targets.csv) remain a separate reference.

`fixtures/output_baseline_checksums.csv` records SHA-256 provenance hashes and MD5 equality checks. MD5 is used by the standard R `tools::md5sum()` function for deterministic regression comparisons; no cryptographic security claim depends on it. The model fixture excludes source-call/environment metadata and the model frame's environment-bearing `terms` attribute; numerical values and sample contents must match exactly.

Fixtures are not regenerated by tests. A deliberate methodological change should be reviewed against both the published targets and this baseline, rather than silently accepting new expectations. Successful tests remove their temporary outputs. On failure, the test retains its workspace outside R's session temporary directory and reports the path for inspection.

## Cached workflow integration checks

```sh
Rscript --vanilla tests/check_workflow.R
```

This uses `_targets.R` with copied raw/reference inputs and a separate cache and output directory. It checks the same exact numerical baseline through the labeled ACS diagnostic exports, verifies the primary revenue Table 2 against independent research evidence, checks unchanged metadata on a cached second run, appropriate dependency invalidation when enrollment/shared/reference files change, and recreation of a deleted table without refitting models. `helpers.R` provides the shared exact-comparison helpers. The uncached regression test remains independent of targets caching.

## Default revenue reconstruction

```sh
Rscript --vanilla tests/check_reconciliation.R
```

This runs the uncached default, checks its full-precision Table 2 CSV byte-for-byte against `research/reconciliation/evidence/revenue_sensitivity_bounds.csv`, verifies the original panel is retained with a separately added revenue field, checks model parameters/sample/df, the independently recorded 20/24 and 22/24 comparison flags, saved model and model data, and unchanged seven original models. The research evidence predates integration into the default workflow; it is not regenerated by the tests.

The workflow suite also tests regeneration of the reporting export without refitting either spending specification or enrollment models. No frozen fixture or published target was changed for this integration.
